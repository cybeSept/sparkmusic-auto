基于 [BeeTap](https://beetap.cn) 开发的自动化脚本：自动进入福利页面、观看广告直播、领取奖励，帮助您快速领取听歌时长。

## 📖 使用教程

### 1. 克隆源码

```bash
git clone <本仓库地址>
```

### 2. 导入脚本到自己的 BeeTap 项目

1. 打开 BeeTap，新建（或打开）一个自己的项目；
2. 将源码中的 `src\js\main.js` 复制 / 导入到**自己项目的** `src\js\` 目录下（替换或覆盖项目默认的 `main.js`）；
3. 按需调整 `BeeTap.toml` 中的配置（如 APP 名称、无障碍服务等）；
4. 连接设备，运行脚本即可。

### 3. 运行前准备

- 开启**截图权限**（脚本运行时会自动申请）；
- 开启**无障碍服务**；
- 目标音乐 APP 保持前台运行。
